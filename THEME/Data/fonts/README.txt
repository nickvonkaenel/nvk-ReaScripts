Quiet theme fonts
=================

Quiet Dark and Quiet Light use two fonts for their intended appearance:

  nvk_SANS-RegularTabular.ttf  - nvk SANS Tabular
  nvk_SANS-RegularUI.ttf       - nvk SANS UI

Install both fonts once. Installing the theme package copies these files to
your computer; it does not install them into your operating system.

When a Quiet theme is active and either font is missing, "nvk_THEME - Settings"
shows a notice with an "Open fonts folder" button. The notice disappears once
both fonts are installed.

Mac
---
Double-click each .ttf file and click Install in Font Book.

Windows
-------
Right-click each .ttf file and choose Install.

Linux
-----
Install both .ttf files with your system's font manager.

If the font has not changed in REAPER after installation, restart REAPER.
